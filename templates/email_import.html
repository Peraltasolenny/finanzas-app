{# Instrucciones Gmail OAuth #}
Cómo configurar Gmail OAuth
  1. Ve a console.cloud.google.com y crea un proyecto.
  2. Activa la Gmail API en "APIs y servicios → Biblioteca".
  3. En "APIs y servicios → Credenciales" crea credenciales de tipo ID de cliente OAuth (aplicación web).
  4. Agrega como URI de redirección autorizada: {{ request.host_url }}importar/correo/callback
  5. Copia el ID de cliente y Secreto y agrégalos a tu .env: 
    GOOGLE_CLIENT_ID=tu_client_id
GOOGLE_CLIENT_SECRET=tu_client_secret
  6. Reinicia el servidor y vuelve a esta página.
